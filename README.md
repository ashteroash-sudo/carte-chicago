# Carte de terrain — Chicago / Gary

## Ajouter ou modifier un quartier
1. Ouvre `chicago/LISTE-DES-DOSSIERS.txt` ou `gary/LISTE-DES-DOSSIERS.txt` pour trouver le nom exact du dossier.
2. Crée le dossier dans la ville (ex. `gary/miller/`).
3. Mets dedans :
   - `texte.txt` : ligne 1 = titre, ligne 2 = sous-titre, ligne vide, puis la description (une ligne vide = nouveau paragraphe).
   - `1.jpg` à `6.jpg` : les photos du collage, en minuscules.
4. Envoie sur GitHub, Vercel redéploie tout seul.

Un quartier sans `texte.txt` affiche « Terrain neutre — pas encore exploré ».
